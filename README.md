## PkgTools

A PowerShell module that contains commands that I use in everyday tasks.

**Convert-RegEscapeCodes** - convert registry escapes
**Convert-RegToGpoXml** - convert reg value of gpo to xml
**Convert-RegToScript** - convert reg file to ps1 script code
**Convert-ResToScript** - convert RES one xml to shortcut script
**Convert-ShortcutToScript** - convert shortcut lnk to ps1 script
**Get-Arp** - get installed products from uninstall reg keys
**Get-Assoc** - get file assocciations
**Get-DnsHostByAddress** - resolve dns name
**Get-FileEncoding** - get file encodiin
**Get-FileLockProcess** - get process that lock the file
**Get-MSIProperty** - get msi properties
**Get-Shortcut** - get infor from lnk file
**Get-SpecialFolder** - get shell folder
**Get-UserGroup** - get users groups
**Import-AppGroup** - create AD groups from preconfigured csv files
**Reset-CsvTestCase** - cleanup csv files from Azure DevOps test suites
**Set-EnUsKeyboard** - set english keyboard
**Set-ShortcutAccess** - change permissions for shortcuts in batch
**Update-ShortcutTarget** - change schortcut target and description in batch
**Zip-File** - Custom way to archive files
